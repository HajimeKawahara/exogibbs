Package graph
=============

Explore the model contracts, evidence, assessments and follow-ups bundled
with ExoGibbs. This saved snapshot includes the package catalog's historical
and current datasets. The :doc:`repository catalog <_generated/catalog>`
also includes source investigations that are not bundled with the package.

.. only:: html

   `Open the package graph in a full window <../_static/package-graph.html>`_.
   The standalone HTML also works offline; external literature links and
   optional citation lookup require an internet connection.

   .. raw:: html

      <iframe src="../_static/package-graph.html"
              title="ExoGibbs package model and evidence graph"
              width="100%" height="900" loading="lazy"
              style="border: 1px solid #ddd;"></iframe>

The viewer preserves the scope of recorded judgments and does not select
an overall validity status. Its language switch translates the interface;
authored scientific records retain their original language.
