CN source packet
================

This offline evidence packet reviews neutral CN without production changes.
Run ``python mceg/reviews/cn_source_review.py`` from the repository root.
``sources.json`` identifies primary inputs and retrieval hashes;
``receipt.json`` binds actual replay dependencies and output.
The archived 75-case grid is an importance screen, not a replacement solve.
See ``documents/mceg/cn_source_review.rst`` for normalization, the scientific
decision, uncertainty limits and the specific candidate follow-up.
