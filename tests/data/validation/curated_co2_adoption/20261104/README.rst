CO2 production adoption
========================

The actual public curated-co2-v1 factory cold-solved 75 ion-inclusive and
75 neutral cases. receipt.json pins the executing sources and numerical
outputs. The existing source/candidate evidence is unchanged. source/ holds
original TiO-default source bytes at ae8bf4f for its historical receipts;
these are not the CO2 execution code. This verifies the adopted implementation
and numerical closure, not physical atmospheric accuracy.
