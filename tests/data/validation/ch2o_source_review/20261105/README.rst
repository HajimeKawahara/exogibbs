CH2O source-review evidence, 2026-11-05
================================================================================

This directory contains selected original NASA blocks, official JANAF numeric
data, ExoMol AYTY PF/definition data and derived source facts. Full articles and
the complete ATcT network are not redistributed. See literature.json for access
limits and sources.json for retrieval hashes. NASA coefficients retain their
original values and bounds; the full NASA source and licence are identified in
src/exogibbs/data/nasa9/NOTICE.txt and LICENSE.txt.

ExoMol data attribution: Al-Refaie et al. (2015), DOI 10.1093/mnras/stv091;
Al-Derzi et al. (2021), DOI 10.1016/j.jqsrt.2021.107563. PF/definition files are
unmodified. These ExoMol data are licensed under CC BY-SA 4.0:
https://creativecommons.org/licenses/by-sa/4.0/ (see also
https://www.exomol.com/data/licence/).

No production update or new equilibrium solve is represented by this archive.
The original curated-cos-v1 endpoints are referenced in place. comparison.json
is regenerated by mceg/reviews/ch2o_source_review.py. receipt.json pins actual
inputs and output; full physical uncertainty remains unknown.
