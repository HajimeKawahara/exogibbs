PH3 source review packet
========================================

Numerical source and partition diagnostics for the named curated-cos-v1 model.
The archived150-case abundance footprint is not a new equilibrium solve.
See sources.json for exact access and redistribution scope; comparison.json is
replayed offline by mceg/reviews/ph3_source_review.py.
The source receipt pins selected implementation/data and numerical output.
No production coefficients are changed.
