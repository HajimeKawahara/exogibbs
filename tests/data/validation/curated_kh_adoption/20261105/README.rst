Curated KH production adoption, 2026-11-05
==========================================

The actual public factory ran 150 fresh cold endpoints, six tighter reference
solves and two independent FastChem checks. Both networks retain curated-oh-v1
species, inventories and all non-KH potentials. The primary tolerance is 5e-14;
tighter candidate controls use 2e-14. The complete command, source hashes and
output hashes are recorded in receipt.json. Earlier source bytes are preserved
under source/ without changing historical receipts. This validates the bounded
numerical adoption, not complete physical uncertainty or atmospheric accuracy.
