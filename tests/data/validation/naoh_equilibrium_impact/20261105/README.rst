NaOH equilibrium impact evidence
================================

Derived offline evidence for the bounded NaOH candidate comparison.
The production baseline is curated-cos-v1; no production adoption is made.
Source facts and access records remain in the separate naoh_source_review packet.
No copyrighted full articles or new OYT data are included.

75 archived current ion-inclusive endpoints are verified and reused; 75 new candidate endpoints
and selected cold/finite-path/secondary controls are stored in ions.npz.
summary.json distinguishes reused and newly executed counts. diagnostics.json and
selected_diagnostics.json record convergence and constraint checks.
receipt.json preserves the actual execution inputs, output hashes and FastChem binary hash.

See documents/mceg/naoh_candidate.rst for scientific choices and limitations.
