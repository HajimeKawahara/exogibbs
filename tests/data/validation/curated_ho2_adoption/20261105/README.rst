HO2 production adoption on curated KH
====================================

The public curated-ho2-v1 factory was executed on 150 cold conditions,
with six tighter independently assembled candidate-on-KH controls and two
FastChem comparisons. Only HO2 changes from curated-kh-v1. The original
HO2 candidate used curated-oh-v1: its thermodynamic column is reused, while
its old abundances are not asserted to equal this new background.

The receipt preserves actual execution inputs and output hashes. Files in
``source`` retain byte-identical earlier inputs when the default changes.
Replay is offline; runtime imports only packaged data and needs no MCEG.
Full atmospheric accuracy and correlated physical uncertainty remain unknown.
