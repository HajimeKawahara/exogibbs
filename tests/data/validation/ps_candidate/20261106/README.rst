PS retained-energy POPS candidate
=================================

The model and validation receipt pin the original source packet, literal FastChem fit, ground-relative state sums, nuclear-spin convention and molecular thermal difference. The central D0 cutoff is fixed; full-distribution, ground-only and lower-cutoff comparisons are sensitivities. No production data are modified.

See ``documents/mceg/ps_candidate.rst`` for the scientific decision and limits.
