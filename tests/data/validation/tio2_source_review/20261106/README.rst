TiO2 source evidence
====================

Offline source tables, selected numerical facts and derived diagnostics for the
Ti(g) + 2 O(g) -> TiO2(g) reaction at one bar. No curated change or new solve.

Run ``python mceg/reviews/tio2_source_review.py``. The receipt pins the source
files, selected implementation dependencies and archived abundance endpoints.
Source access and outside-repository full-document hashes are in sources.json.
