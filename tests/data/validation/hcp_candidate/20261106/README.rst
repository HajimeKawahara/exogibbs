HCP retained-thermal candidate packet
=====================================

``candidate.json`` pins two independent common-reference energy alternatives
for neutral H-C-P. ``validation.json`` checks continuous G/H/S/Cp, the actual
named production baseline and retained source-fit residuals at 2501 temperatures.
``receipt.json`` records the actual build command and exact input/output hashes.
The original HCP source packet is unchanged. Later tests and explanatory docs
are pinned separately in ``mceg/contracts/hcp_candidate.yaml``.

Physical D0 is distinguished from the empirical R*a fit intercept. CCCBDB and
the 2001 Hf0 anchor raise G/H by 62308 and 73808 J/mol respectively; neither
changes S/Cp or adopts a new thermal model. Quoted source widths are finite
sensitivities, not confidence intervals. Production is unchanged.
