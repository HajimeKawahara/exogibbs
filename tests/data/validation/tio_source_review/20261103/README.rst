TiO source review, 2026-11-03
===========================

This compact packet supports a source assessment, not curated adoption.
``literature.json`` records source zeros, inspection scope and pending ancestry.
``exomol_nodes.json`` preserves selected official numerical PF nodes for five
isotopologues, definition metadata and hashes of whole downloaded files. Its
current-state sums are acquisition-time summaries, not an offline regeneration
of all 301245 levels. ``sources.json`` distinguishes inspected primary full texts,
abstracts and bibliographic leads. Large papers and line lists are not vendored.

Replay ``mceg/reviews/tio_source_review.py`` against the pinned existing
major-molecule source fixture and 75-case gas-only archive. ``comparison.json``
is that output. ``receipt.json`` and the v0.2 MCEG contract pin dependencies.
The review separates molecular mass, nuclear spin, ground-zero D0 and internal
thermal changes. A fixed-mass monoisotope diagnostic is not a natural-isotope
thermochemical replacement. No new solve, opacity calculation or condensation
model was performed, and no production data changed.
