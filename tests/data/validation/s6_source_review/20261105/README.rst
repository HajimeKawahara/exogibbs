S6 source-review evidence, 2026-11-05
======================================

``inputs.json`` contains selected factual JANAF values and labelled modern
source facts. ``nasa-record.txt`` contains the public NASA numerical record.
``sources.json`` distinguishes inspected full text, abstract-only access and
unrecovered material; document hashes identify temporary inspected bytes.
``comparison.json`` is an offline replay and reads the existing latest
curated-cos grid. It is not a replacement run or physical uncertainty bound.
``receipt.json`` pins the consumed sources, implementation and outputs.
No full paper, default preset change or new equilibrium solution is included.

See ``documents/mceg/s6_source_review.rst`` for scientific decisions,
references and concrete follow-up calculations.
