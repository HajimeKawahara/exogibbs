OH source review, 2026-11-05
==========================

The packet records the inherited JANAF/FastChem column and the known OH
electronic-degeneracy/caloric defect identified by IUPAC 2005. It supports
prioritizing a NASA/ATcT replacement candidate with a MYTHOS thermal comparison,
not a production change or finite-substitution result.

states.npz retains every downloaded MYTHOS and MoLLIST-OH state's energy,
weight, J, electronic label index and v. state_inventory.json maps the columns,
pins raw bytes and retains selected published PF nodes. No energy-zero or
degeneracy correction is inserted during extraction. Nuclear spin two is
removed once during evaluation. The actual MoLLIST count differs from metadata.

JANAF text tables and selected NASA records preserve numerical source data;
the NASA header metadata are parsed into literature.json. sources.json records
URLs, raw hashes, normalized archive hashes and inspection/access limits.
Full papers, HTML pages and original state/PF downloads remain outside git.
IUPAC numeric nodes are factual selected values; the paper was inspected via
the official author-hosted PDF web view, without a local download.

comparison.json is regenerated by mceg/reviews/oh_source_review.py using these
data and pinned existing references. The current footprint uses 75 archived
curated-h2o-v1 endpoints; neither new abundances nor full physical accuracy are
claimed. See documents/mceg/oh_source_review.rst for conventions and decisions.
