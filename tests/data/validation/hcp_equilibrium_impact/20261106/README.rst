HCP two-anchor finite-network evidence
======================================

The two archives contain the same verified current baseline and two independent
HCP substitutions, with 75 conditions and 537 ion-inclusive or 421 neutral
species. Exactly 300 new main endpoints use 150 shared archived baseline cases.
The 28 cold controls comprise 12 tighter endpoints and 16 quoted-energy edges.
Four standalone FastChem executions are two current/candidate pairs at one
distinct thermodynamic condition; the current model is executed twice.

Amounts and thermodynamic potentials are unfloored. The archives retain formula
matrices, budgets, condition arrays, selected controls and unresolved same-model
Gibbs comparisons. ``summary.json`` reports phosphorus redistribution and scope;
``diagnostics.json`` and ``selected_diagnostics.json`` record actual convergence.
``receipt.json`` is copied with the outputs from the original ignored run
directory without changing its execution command, hashes or scientific values.
Tests and later documentation are pinned independently by the candidate contract.

No production update, modern thermal replacement or full physical uncertainty
claim is made. Source-reported widths are sampled only at two selected conditions
in each network; they are not a full-grid uncertainty envelope.
