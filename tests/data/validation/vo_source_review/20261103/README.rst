VO source review, 2026-11-03
============================

This packet freezes official JANAF numerical tables, an ExoMol definition,
selected partition rows and factual literature notes. Full research papers
and partition downloads are not redistributed; sources.json records URLs,
download hashes and inspection limits. Merriles2020 was read as rendered
author-manuscript full text, although direct PDF retrieval failed.

comparison.json is regenerated offline by mceg/reviews/vo_source_review.py.
receipt.json pins the code, source dependencies, review and output. The
current hybrid and the existing 75-case footprint are checked without a
new equilibrium solve. Modern Q/8 comparisons hold current D0 and NASA
atoms fixed, adjust the molecular translational mass and assume unresolved
energy-zero alignment. They are diagnostic, not a curated update.
