Potassium hydroxide dimer evidence packet
=========================================

Replay offline from the repository root::

   python mceg/reviews/koh_dimer_source_review.py
   pytest tests/model_evidence/koh_dimer_source_review_test.py

The packet freezes official JANAF nodes, numerical excerpts from Gurvich1997,
source inspection limits and DOI metadata. Numerical replay uses the existing
#309 NASA/atomic snapshot and solved curated-c2h-v1 archive. Full articles are
not redistributed. No production coefficients or new equilibrium solutions.

Exact-node source decomposition, published thermal-function representation,
harmonic/rotor diagnostics and potassium inventory accounting are distinct
from complete original-source confirmation and physical model validation.
The receipt pins all input and output files; MCEG keeps scientific follow-ups.
