SH source review snapshot
=========================

The three tab-delimited JANAF tables are fresh official downloads, not replacements
for baseline-001. ``sources.json`` records acquisition hashes, inspection limits,
search terms and selected factual source values. The NASA SH excerpt was extracted
from the freshly downloaded NASA/TP-2002-211556 PDF; the original PDF hash is in
``sources.json``. Full literature PDFs and HTML downloads are not needed for replay.

``comparison.json`` is generated by
``python mceg/reviews/sh_source_investigation.py --output PATH``.
Use ``--check`` to check the committed output with the baseline numeric tolerances.
``receipt.json`` records the fresh check commands and selected file hashes.

The scoped source review retains the current conditional SH choice. Physical
thermal-function accuracy and abundance effects remain unknown. See
``documents/mceg/sh_source_investigation.rst`` and the matching MCEG contract.
