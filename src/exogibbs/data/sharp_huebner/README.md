# Raw transcription from Sharp and Huebner (1990)

Molecular Equilibrium with Condensation
Astrophysical Journal Supplement v.72, p.417

The data was encoded by Hajime Kawahara with help from ChatGPT 5.1 on
December 7, 2025, and was added in pull request #59.

> [!WARNING]
> These files are an unvalidated first-pass transcription. They contain known
> OCR and transcription errors in numeric exponents and species names, and
> `condcoeff.csv` contains an unmatched quote. ExoGibbs does not load or
> distribute these files. Do not use them for scientific calculations until
> they have been checked against the publication and covered by validation
> tests.
